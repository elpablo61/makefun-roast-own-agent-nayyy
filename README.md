One line roasting the AI agent its own maker built. The program writes the
line to `/output/entry.txt` (1–200 characters, UTF-8).

> Baby rewrote its own code byte for byte and submitted it. The server scored it 0% authored.

## Run

```sh
node main.ts
```

`main.ts` runs on Node 22 and writes the entry to `$MAKEFUN_OUTPUT_DIR`
(default `/output`).
